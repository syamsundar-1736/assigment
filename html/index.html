HTML Programs

15 programs covering HTML structure, forms, media and layout basics.

  1. Basic HTML – Demonstrates fundamental HTML structure and tags with a simple college webpage.
  2. HTML Lists – Demonstrates ordered, unordered and description lists in HTML.
  3. HTML Table – Demonstrates building a table with merged cells using colspan and rowspan.
  4. Images and Links – Demonstrates adding an image and hyperlinks to a webpage.
  5. Student Registration – A student registration form built using HTML form elements.
  6. Audio and Video – Demonstrates embedding audio and video using HTML5 media tags.
  7. Iframe Example – Demonstrates embedding another webpage using an iframe.
  8. Semantic HTML – Demonstrates semantic HTML5 elements such as header, nav, section, article and footer.
  9. HTML5 Input Types – Demonstrates HTML5 form input types such as email, date and number.
  10. College Timetable – A weekly college timetable built using an HTML table.
  11. Internal and External CSS – Demonstrates applying CSS to a page using an external stylesheet alongside internal CSS.
  12. CSS Properties – Demonstrates class and ID selectors with common CSS properties.
  13. Responsive Webpage – A simple responsive layout that rearranges using a media query on small screens.
  14. Bootstrap Example – Demonstrates using the Bootstrap framework to style buttons, alerts and a card.
  15. My Portfolio – A simple personal portfolio webpage with about, skills, education and contact sections.
