## How to Use

1. Open `index.html` in any web browser — this is the home dashboard.
2. Click **View HTML Programs**, **View CSS Programs**, **View JavaScript Programs**, or **View JavaScript Lab**
   to open that section's program list.
3. Click any program title to open it. Every program page includes a
   **Home** link and a link back to its category list, so you can navigate
   the entire project without typing file names.

## Interactive Website Features

The home dashboard (`index.html`) includes:

- Light / dark theme toggle
- Responsive mobile navigation
- Animated program counters
- Search box for program categories
- HTML / CSS / JavaScript / JS Lab filters
- Interactive hover effects and responsive cards
- GitHub Pages-friendly relative links
